# Airbnb Analysis

Interactive Tableau dashboard analyzing Airbnb listing elements and pricing patterns.

## Dashboard

[View the interactive Tableau dashboard](https://public.tableau.com/app/profile/yihan.wang3857/viz/AirBnB-Analysis_17900352269310/Dashboard1?publish=yes)

![Airbnb Dashboard](images/Dashboard.png)

## Tools
- Tableau
- Data Visualization
- Data Analysis
- Kaggle

### Key Questions
* How do Airbnb prices vary by ZIP code?
* How do Airbnb prices change throughout 2016?
* How does the number of bedrooms relate to listing price?
* How are listings distributed by number of bedrooms?
